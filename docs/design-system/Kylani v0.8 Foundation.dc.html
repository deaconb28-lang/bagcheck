Usage conventions

No new brand. These are the application rules every v0.8 screen inherits: what the accent means, how status reads, how a card is built, and how the funnel is drawn.

The accent rule

Ember = Kylani did something

Reserved for the agent status chip, new signals, and anything awaiting approval. Never used for generic decoration, hover fills, or section headers inside the app.

Green = shipped or won

Sent, posted, converted. Errors use ink text on a sand field with an ember hairline — no red is added to the palette.

Mono is for machine facts only

Buttons

Ink is the primary in-app action. Ember-filled buttons appear only on marketing surfaces and first-run moments, so ember stays meaningful in the app. Every label names what happens.

Interface copy

Rules Plain nav names. Sentence case. No exclamation marks. Buttons name their action. Kylani is “Kylani” or “it” — never “she” or “they”.
Empty states name the next move “Kylani's first sweep is running — 23 sources to check.” Not “nothing here yet.”
